# How to Apply Custom CSS to Your Squarespace Website

## The Problem
Your website currently uses **blue colors** (#3498db, #3a6ea5) but your logo uses **muted plum/purple** (#5a4a6b). This creates a visual disconnect.

## The Solution
I've created custom CSS that transforms your website to match your logo's color palette perfectly.

---

## Step-by-Step Instructions

### 1. Log into Squarespace
Go to https://www.squarespace.com and log into your account

### 2. Access Custom CSS Editor
1. Click on your website
2. Click **"Design"** in the left sidebar
3. Click **"Custom CSS"**

### 3. Add the Custom CSS (BOTH FILES!)
You need to add TWO CSS files:

#### File 1: Color Fixes (squarespace-custom-css.css)
1. Open the file `squarespace-custom-css.css` (in this folder)
2. **Copy ALL the CSS code** from that file
3. **Paste it into the Custom CSS editor** in Squarespace

#### File 2: Layout Fixes (squarespace-layout-fixes.css)
1. Open the file `squarespace-layout-fixes.css` (in this folder)
2. **Copy ALL the CSS code** from that file
3. **Paste it BELOW the first CSS** in the Custom CSS editor
4. Click **"Save"** in the top left

### 4. Preview Your Changes
- Use the preview button to see how it looks
- Check both desktop and mobile views
- Navigate through different pages to ensure consistency

### 5. Publish
Once you're happy with the changes, click **"Publish"** in the top right corner
